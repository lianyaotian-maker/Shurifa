# 草原小屋

黄昏的草原上，有一间亮着灯的小木屋，门廊上住着一只叫鸡柳的橘猫。

一个用 three.js 写的第一人称小网页，为手机横屏设计（iPhone / iPad 的 Safari 都能打开），不用安装任何东西。

## 怎么玩

- **左边按住拖动**：走路
- **右边滑动**：环顾四周
- **点一点**：看到闪光的小星星就点一下，看看会发生什么
- **上方的日期条**：拨动日期，草原会随四季慢慢变化（打开时默认是今天）
- 左上角可以开关声音，右上角可以切换画质（流畅 / 均衡 / 精美），画面也会根据设备自动调节清晰度
- 电脑上也能玩：WASD 走路，鼠标拖动环顾，空格跳

想全屏玩：在 iPhone Safari 点「分享」→「添加到主屏幕」，从主屏幕打开就是全屏横屏。

## 鸡柳

- 会自己走动、打盹、舔毛，看到你会小跑过来
- 摸摸它：会喵喵叫、打呼噜、冒爱心；连着摸三下，它会躺下露肚皮
- 被摸过之后会跟着你走一会儿
- 点门廊上的猫食盆，它会跑过来吃
- 冬天会戴上小围巾

## 可以点的东西

屋外：风铃、树下的秋千（走近点是坐上去，远处点是推一把）、山顶的长椅（坐下看夕阳）、信箱、路边的蒲公英、冬天的雪人、猫食盆。

屋里：货架和面山上的每一包面、桌上那碗面、八音盒、吊灯。

## 声音

所有声音都是实时合成的，没有用任何音频文件。声音在点了「走进草原」之后才会启动。

## 发布到 GitHub Pages

1. 打开仓库的 **Settings → Pages**
2. **Source** 选 **Deploy from a branch**
3. **Branch** 选放着这些文件的分支，文件夹选 **/(root)**，点 **Save**
4. 等一两分钟，页面顶部会出现网址：`https://<用户名>.github.io/<仓库名>/`

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` / `style.css` | 页面和界面 |
| `js/three.min.js` | three.js r147（放在本地，不依赖外部 CDN） |
| `js/core.js` | 公共工具、共享参数、雾 |
| `js/season.js` | 日期与四季的颜色关键帧 |
| `js/field.js` | 地形、小路、树的位置，烘焙阴影 |
| `js/shaders.js` | 草、地面、天空、远山、野花、粒子、室内的着色器 |
| `js/post.js` | 柔光、夕阳光束、调色（带自检，不支持时自动关闭） |
| `js/nature.js` | 天空、远山、地面、随风摆动的草和野花 |
| `js/trees.js` | 树（橡树、樱花树、松树） |
| `js/house.js` | 北欧红色小木屋 |
| `js/interior.js` | 屋里的一切 |
| `js/fx.js` | 花瓣、落叶、雪、萤火虫、炊烟等粒子 |
| `js/party.js` | 某一天才会出现的东西 |
| `js/audio.js` | 声音合成（猫叫、呼噜、风铃、八音盒、小音效） |
| `js/things.js` / `js/things2.js` | 可以点的东西和小粒子（爱心、音符等） |
| `js/cat.js` | 鸡柳 |
| `js/life.js` | 飞鸟和蝴蝶 |
| `js/player.js` | 第一人称操作与碰撞 |
| `js/main.js` | 主循环、日期条、互动、画质 |
